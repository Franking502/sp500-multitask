# `sp500_features.csv` 字段说明

| 项目 | 内容 |
| --- | --- |
| 文件 | `data/processed/sp500_features.csv` |
| 生成脚本 | `src/0_DataPreprocessing/DataDescription.py`（`FeatureEngineer.build()` → `save_features()`） |
| 命令 | `python src/0_DataPreprocessing/DataDescription.py` |
| 形状 | 7,347 行 × 45 列（16 个基础列 + 29 个特征列） |
| 时间范围 | 1997-08-29 ~ 2026-11-13（7,347 个交易日） |
| 缺失 | 无：所有列均已剔除预热期，可直接用于建模 |
| 价格口径 | 标普 500 指数点位（未复权、非全收益） |

## 与 `sp500_clean.csv` 的关系

- 生成顺序：先运行 `DataPreprocessing.py` 产出 `sp500_clean.csv`，再运行 `DataDescription.py` 产出本文件。
- 前 16 列与 `sp500_clean.csv` 同名同义，字段含义见 [`sp500_clean_fields.md`](sp500_clean_fields.md)。
- 行数少 199 行：`ma_200` 需要 200 个交易日才能得到第一个有效值，因此前 199 行属于指标预热期，`build(dropna=True)` 已将其剔除，本文件从 1997-08-29 开始。
- `segment` 分布：train 5,083 行、val 1,132 行、test 1,132 行（训练集减少的部分即被剔除的预热期）。

## 建模使用建议

1. **特征清单**：用 `FeatureEngineer.feature_columns()` 获取上述 29 列，它已自动排除 OHLCV、`is_filled`、`segment` 以及当期的 `ret` / `log_ret`。
2. **防泄漏**：`ret`、`log_ret` 是「当期」收益，若预测目标是次日涨跌，它们属于标签或同期信息，不能作为特征；请使用 `log_ret_lag_1..5`。
3. **`segment` 只用于切分**：训练 / 验证 / 测试必须按时间顺序，切勿随机打乱，也不要把它当特征喂给模型。
4. **量纲不一致**：`ma_*`、`ema_*`、`macd*`、`bb_mid/upper/lower`、`atr_14` 与价格同量纲（点位，约 700~7800），`ma_ratio_*`、`bb_pctb_*`、`bb_width_*`、`vol_*`、`log_ret_lag_*` 为无量纲比例；树模型可不处理，线性模型 / 神经网络建议标准化。
5. **取值范围**：`rsi_14` 在 0~100 之间；`bb_pctb_20` 可越界（价格突破上下轨时小于 0 或大于 1），属正常现象，不要截断。
6. **MACD 与 ATR 的口径**：均使用 `adjust=False` 的指数平滑与 `min_periods = 窗口`，与常见行情软件（TA-Lib 口径）一致，早于窗口的值为 NaN（本文件已剔除）。
7. **扩展特征**：需要更长/更短的窗口时，用 `FeatureEngineer.build(config={...})` 重建，例如 `{"ma_windows": (10, 20), "lags": (1, 2, 3)}`，不要手工改 CSV 以免与脚本脱节。
8. **复现**：本说明依据当前 CSV 的实际内容生成；重新运行 `DataDescription.py` 会覆盖 CSV，若特征配置变化，请同步更新本文档。
